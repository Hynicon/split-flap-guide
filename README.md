# Split-flap build guide

A step-by-step build guide for a split-flap display, with 3D assembly diagrams, wiring drawings and a progress checklist.

Open it here: https://hynicon.github.io/split-flap-guide/

The firmware, the phone app and the remote relay server (Docker, Portainer) are in [Hynicon/split-flap](https://github.com/Hynicon/split-flap).

## Credits

The display design, the case and unit geometry shown in the 3D diagrams, and the photos are by David Königsmann
([Printables 69464](https://www.printables.com/model/69464), [split-flap on GitHub](https://github.com/davidkingsman/split-flap)).
This guide adapts his instructions for a shortened case, hand-soldered boards and an ESP32.
